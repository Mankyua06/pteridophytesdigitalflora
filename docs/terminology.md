# Public terminology

The site uses **Pteridophyte Digital Flora** as its name and **Pteridophytes of Korea / 한국의 양치류** for its scope. The public description explicitly includes ferns and lycophytes. This follows the user's requested scope; the broader use of pteridophytes is illustrated in the [Cambridge botanical reference](https://assets.cambridge.org/97805217/07725/excerpt/9780521707725_excerpt.pdf).

The review covers navigation branding, document titles, homepage text, footer, statistics description, contributor invitation, and English/Korean Excel interface text. Generic 고사리류 and 양치식물 wording in interface text is standardized to 양치류. Recorded taxon names and morphology terminology remain unchanged.

Existing identifiers such as `fern_digital_flora`, `documenting_ferns`, and `korean_ferns` remain stable Excel text keys. The folder, workbook filename, storage bucket, and language cookie also retain their technical identifiers to preserve existing paths, data links, and saved language preferences. Their public display values use the new terminology.
